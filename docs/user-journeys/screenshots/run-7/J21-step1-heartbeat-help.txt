usage: python -m router.bingx_heartbeat [-h] [--max-age-hours MAX_AGE_HOURS]

Check the scheduled BingX VST bot's heartbeat: read the newest slot completion
and send an urgent Telegram alert (once per stale slot) when none has finished
within --max-age-hours. Exit 0 when the bot is fresh, 1 when it is stale or
absent.

options:
  -h, --help            show this help message and exit
  --max-age-hours MAX_AGE_HOURS
                        how long the bot may go without finishing a slot
                        before it is stale (default 5)
